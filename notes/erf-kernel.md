# Error-function kernel effects

Date: 17 October 2026

## Setup
Same two-parameter protocol as the logistic test: width linear in rate, apparent onset shifted linearly. Switch replaced by an error function.

## Findings
- Peak height falls with rate, but absolute heights are lower than under logistic smearing at the same nominal width.
- FWHM increases monotonically across the sampled rates.
- Peak location tracks the imposed φc closely.
- Onset is more symmetric than the logistic case.

## Interpretation
The error-function kernel produces a cleaner, more symmetric rate trend. The non-monotonic width seen under logistic smearing is absent. Peak-height decline remains a stable feature across both kernels.

## Status
Kernel choice affects width morphology. Monotonic broadening under erf is the more regular synthetic result.
