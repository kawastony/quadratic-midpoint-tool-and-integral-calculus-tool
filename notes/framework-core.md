# Framework core statement

Date: 16 October 2026

## 1. Universal kinematics
The six locked laws define an inward transmission geometry (cone/funnel under load, shell composition, reciprocal closure, equal active/pause phases, acceleration equal to the field, one-end regularity). This is the universal form. It does not select a hard ceiling.

## 2. Constitutive capacity
Finite local transmission capacity is an additional axiom. It is not derived from the locked laws. It places the medium in the barrier universality class: domain 0 ≤ u < u★ with V'(u) → ∞ as u → u★⁻.

## 3. Candidate distinction
- A (elastic): unbounded linear response.
- B (quartic): sublinear stiffening, no hard ceiling.
- C (capacity-limited): incremental response collapses; u₀ → u★ from below.

Only C produces a true jammed plateau.

## 4. Observables and plateau criterion
Monotone load J₀, response u, incremental slope Δu/ΔJ₀. Plateau when Δu/ΔJ₀ → 0 while u remains bounded by u★. Crossover load J₀* marks the onset of visible saturation.

## 5. Claims / non-claims
Explains the saturated inward environment and the collapse of incremental response under finite local capacity. Does not derive tunneling probabilities, nuclear cross-sections, binding energies, or replace GR/QM. May describe the container conditions in which such processes occur.
