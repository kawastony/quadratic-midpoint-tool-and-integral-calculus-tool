# Onset model

Date: 16 October 2026

## Purpose
Produce the discontinuous jump in coordination at the isostatic point. Separate from the continuous UZ-1 bridge that governs post-lock growth.

## Variables
- φ: packing fraction
- φc: jamming threshold
- z: coordination
- zc = 2d: isostatic value

## Minimal onset rule
If φ < φc:
  z = 0
If φ ≥ φc:
  z = zc + a (φ - φc)^β

The jump is from 0 to zc at φ = φc. Post-jump growth is continuous (UZ-1 compatible).

## Rigidity order parameter
R = 0 for φ < φc
R = 1 for φ ≥ φc

## Status
Toy onset. Reproduces the known isostatic discontinuity. Does not derive φc or zc from the locked laws. Coupling to capacity u remains open.
