# Synthetic L-H-like mismatch test

Date: 17 October 2026

## Setup
External drive: input power P ramped linearly.
Internal response: confinement metric Q rises through an error-function switch at a prescribed threshold P_thr = 1.8.
Mismatch: dQ/dP.

## Result
Mismatch peak located at P = 1.796. Absolute error relative to the imposed threshold: 0.004. Peak height = 10.51.

## Interpretation
Under a slow synthetic ramp the derivative diagnostic recovers the imposed threshold location. This is a pipeline check only.

## Status
No real fusion data were used. EPED and ELITE were not run. The test confirms that the mismatch peak tracks an abrupt internal reorganization under continuous drive in a toy setting.
